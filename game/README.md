# Project SENTINEL

An original 3D game experiment exploring adaptive AI agents, protective behavior, and the relationship between objectives and decisions. Inspired by questions raised by science-fiction games and films; not a recreation of any copyrighted characters.

## Day 1 — Arena prototype

- 3D arena, player movement (WASD / arrow keys), orbit camera
- Guardian and Adversary placeholders
- **No AI or combat yet**; these are planned for later iterations.

## Run locally

Requires Node.js 20+.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (typically http://localhost:5173).

## Planned milestones

1. Combat, health, collision detection
2. Finite-state-machine AI
3. Adaptive player behavior tracking and utility scoring
4. Guardian decisions and consequence mechanics
5. Evaluation, documentation, deployment
